# mypackage

Production-ready src-layout Python package template with uv.lock, pytest, Ruff, and pre-commit.

## Features

- **uv** for fast dependency management and reproducible builds via `uv.lock`
- **pytest** with coverage, xdist parallelization, and strict configuration
- **Ruff** for linting and formatting (replaces flake8, isort, black, pyupgrade)
- **MyPy** for strict static type checking
- **pre-commit** hooks for automated quality gates
- **GitHub Actions** CI with matrix testing (3.11, 3.12, 3.13), security scanning, and artifact publishing
- **Bandit** + **pip-audit** for security scanning with JSON artifact upload
- **src-layout** package structure with PEP 561 typing support

## Quick Start

```bash
# Clone and enter the template
git clone <this-template> myproject
cd myproject

# Initialize with uv (creates uv.lock)
uv sync --dev

# Install pre-commit hooks
uv run pre-commit install

# Run tests
uv run pytest

# Run linting and formatting
uv run ruff check .
uv run ruff format --check .

# Run type checking
uv run mypy --strict src/
```

## Development Workflow

### Dependency Management

```bash
# Add a runtime dependency
uv add requests

# Add a development dependency
uv add --dev pytest-mock

# Update dependencies (updates uv.lock)
uv lock --upgrade

# Sync environment to lockfile
uv sync --dev --frozen
```

### Running Checks Locally

```bash
# All pre-commit hooks
uv run pre-commit run --all-files

# Individual tools
uv run ruff check .
uv run ruff format --check .
uv run mypy --strict src/
uv run pytest --cov=src/mypackage --cov-fail-under=80
uv run bandit -ll --recursive --skip B101 src/
uv run pip-audit
```

### CI Pipeline

The GitHub Actions workflow (`.github/workflows/ci.yml`) runs on every push and PR:

1. **Lint** - Ruff check + format
2. **Type Check** - MyPy strict mode
3. **Test** - pytest matrix across Python 3.11, 3.12, 3.13 with coverage
4. **Security** - Bandit SAST + pip-audit SCA with JSON artifact upload
5. **Pre-commit** - All hooks on all files
6. **Build** - Package build on main branch pushes

## Customization

### Rename the Package

1. Rename `src/mypackage/` to `src/yourpackage/`
2. Update `pyproject.toml`:
   - `name = "yourpackage"`
   - `[tool.hatch.build.targets.wheel]` packages = ["src/yourpackage"]
3. Update import statements in tests and source code
4. Update coverage source in `[tool.coverage.run]` and `[tool.pytest.ini_options]`

### Adjust Coverage Threshold

Modify `--cov-fail-under=80` in:
- `pyproject.toml` `[tool.pytest.ini_options].addopts`
- `.github/workflows/ci.yml` test job

### Add More Python Versions

Update the matrix in `.github/workflows/ci.yml`:
```yaml
strategy:
  matrix:
    python-version: ["3.11", "3.12", "3.13", "3.14"]
```

Also update `requires-python` and classifiers in `pyproject.toml`.
